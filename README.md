# DANDY — Bags for every journey

Premium bag brand website (Karur, Tamil Nadu). School, college, backpacks, travel, sling, handbags, ladies purses.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Copy `.env.example` to `.env.local` for WhatsApp / social URLs.

## Notes

- Product specs and retail prices are placeholders until the owner supplies data.
- B2B wholesale prices are stored in data but never rendered on public pages.
- Do not invent dealer names, DMart/Reliance vendor status, or factory capacity.
